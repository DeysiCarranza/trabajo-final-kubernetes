# 🚀 Trabajo Final  - Kubernetes

## 📖 Descripción del Proyecto

Este repositorio contiene el desarrollo del Trabajo Final de la materia **Administración de Sistemas Avanzadas**.

El proyecto consiste en implementar el despliegue automatizado de una aplicación web en Kubernetes, utilizando contenedores y archivos de configuración YAML. 
Además del despliegue de la aplicación, se realizará una demostración de tolerancia a fallos mediante el uso de múltiples réplicas, verificando la recuperación automática ante la caída de un pod. También se incorporará monitoreo básico para observar el estado de los recursos desplegados.

## 🎯 Objetivos

* Desplegar una aplicación web en Kubernetes.
* Automatizar el proceso de despliegue mediante scripts.
* Utilizar archivos YAML para definir los recursos del clúster.
* Implementar múltiples réplicas para mejorar la disponibilidad.
* Demostrar la recuperación automática ante fallos.
* Incorporar monitoreo básico del entorno.
* Documentar todas las etapas del proyecto.
